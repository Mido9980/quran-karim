# Коран Карим · القرآن الكريم

Полный текст Корана (6236 аятов, 114 сур) с переводом, аят за аятом. Офлайн-PWA.

- Чтение: список сур с поиском, чтение суры с переводом под каждым аятом
- 8 переводов: русский (Кулиев), English, Français, Deutsch, Español, Türkçe, Indonesia, اردو
- Перевод можно скрыть, размер текста настраивается отдельно для арабского и перевода
- 2 темы (ночная/дневная), 2 языка интерфейса (русский / العربية)
- Продолжение чтения, закладки, копирование иотправка аята, ссылки вида #/s/2/255
- Офлайн: service worker кэширует текст, шрифты и переводы

Данные: `data/ar.json` (текст), `data/<lang>.json` (переводы), `data/surahs.json` (названия сур).
